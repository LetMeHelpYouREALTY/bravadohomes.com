## ⏳ What You Need to Do

### Single Action Required: Add Verification Code

**Step 1**: Get verification code from Google Search Console
1. Go to https://search.google.com/search-console
2. Add property: `bravadohomes.com`
3. Choose "HTML tag" verification method
4. Copy the verification code

**Step 2**: Add to Vercel
1. Go to Vercel Dashboard → Your Project → Settings → Environment Variables
2. Add new variable:
   - **Name**: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
   - **Value**: `[your verification code]`
   - **Environments**: Production, Preview, Development
3. Save and redeploy

**Step 3**: Verify
1. Return to Google Search Console
2. Click "Verify"
3. Submit sitemap: `https://bravadohomes.com/sitemap.xml`
